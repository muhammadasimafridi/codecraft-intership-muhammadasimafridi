# Expense Tracker

A simple and responsive **Expense Tracker** built using **HTML**, **CSS**, and **JavaScript**. This application helps users record and manage their income and expenses while keeping track of their current balance in an organized and user-friendly interface.

## Features

* Add income and expense transactions
* Automatically calculate the total income
* Automatically calculate the total expenses
* Display the current balance
* Delete transactions when needed
* Instant updates using JavaScript
* Clean and responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How It Works

1. Enter a transaction description.
2. Enter the transaction amount.
3. Choose whether it is **Income** or **Expense**.
4. The application updates the totals and current balance automatically.
5. Delete any transaction whenever required.
